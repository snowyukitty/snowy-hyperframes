# Storyboard: 2026 年最新 TTS 與 AI Voice Clone 技術研究

**專案：** latest-tts-voice-clone-research  
**總時長：** 180 秒（3 分鐘）  
**語言：** 繁體中文

**目標觀眾：** 正在製作 AI 影片、自動旁白、技術解說影片的創作者

## 影片概覽

這部 HyperFrames 影片以研究為導向，回答創作者最關切的問題：**「我們下一步應該如何讓 Snowy HyperFrames 的 AI 旁白更自然？」**

整部影片由 11 個 slide 組成，分為三個部分：

1. **現狀診斷** (Slides 1-2)：認識 Edge-TTS 的優勢與限制
2. **技術選項** (Slides 3-6)：探索商用、開源、法律框架
3. **可執行路線圖** (Slides 7-11)：短中長期建議與決策清單

**旁白內容：**

## 旁白策略

### 檔案結構
每個 slide 將生成兩個文本文件：

1. **slide-XX.display.txt**
   - 用於觀眾看到的字幕與轉錄
   - 保持原始表述和格式

2. **slide-XX.tts.txt**
   - 用於 Edge-TTS 輸入
   - 應用 pronunciation map 替換（GPT → G P T 等）
   - 最佳化朗讀流暢度與自然度

### Pronunciation Map 應用
使用 `shared/data/pronunciation-map.json` 規則集，自動轉換：
- 技術詞：API → A P I，GPT → G P T，TTS → T T S
- 產品名：OpenAI → Open A I，ChatGPT → Chat G P T，ElevenLabs → Eleven Labs
- 計畫名：Free/Plus/Pro → 免費版/Plus 版/Pro 版
- 技術術語：voice clone → 聲音複製，prosody → 韻律，etc.

### 聲音選擇
- **工具：** Edge-TTS
- **聲音：** zh-TW-HsiaoChenNeural
- **速率：** +0%（正常速度）
- **音調：** +0Hz（正常音調）
- **音量：** +0%（正常音量）
