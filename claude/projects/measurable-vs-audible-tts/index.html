08 / 10
method

把只能聽的，變成十分鐘的事

  1. 同一段稿子，A／B 兩個播放器，順序每段不同
  2. 引擎名稱與客觀數據都藏到「揭曉」之後
  3. 選完八段，一鍵複製成 markdown 結論

產生方式：npm run bakeoff（shared/tools/hf.mjs）

盲測聽測包：標籤與數據都藏到揭曉之後，聽完按一顆按鈕就有結論。
09 / 10
outro

方法比結論先到

能量的先量完；不能量的，把它變便宜。

量得到

語速、停頓、響度一致性、生成成本——用 ffmpeg，十六段全量。

量不到

自然度。沒有客觀指標，只有耳朵，所以不寫進結論。

做法

把聽測做成盲測網頁，讓那一半從「有空再說」變成十分鐘。

本片狀態：ready-to-preview。人工審核包由 npm run review 產生。

能量的先量完，不能量的準備好給人聽。這支影片本身也還沒過人工那一關。
