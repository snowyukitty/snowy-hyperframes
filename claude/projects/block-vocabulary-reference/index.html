metrics

metrics：讓一個數字占住視線

這一頁的每個數字都來自本 repo 自己的規則。

block 類型
6
lead · metrics · cards · list · quote · source
一頁上限
3
超過三個 block 就該拆頁
安全邊界
0.6s
旁白結束後保留的呼吸空間

來源：shared/tools/hf.mjs 的 BLOCK_TYPES 與 BLOCK_LIMITS（本 repo 內可驗證）。

數字用 metrics：標籤在上、數值在中、註解在下，一列二到四個。
01 / 05
cards

cards：三個並列的概念

官方

廠商自己公布的數字，可直接引用。

社群

使用者實測回報，需標明樣本與日期。

估算

我們推導的數字，必須寫明推導方式。

概念用 cards，標題一行、說明兩行以內。
02 / 05
list

list：一次講五件事的上限

  1. storyboard 寫下意圖
  2. prepare-tts 產生朗讀稿
  3. tts 生成旁白
  4. measure 量測實際長度
  5. sync 回寫所有時間軸
步驟用 list，最多五項，超過就拆頁。
03 / 05
quote

quote：讓一句話占住畫面

此規則來自 2026-06 的旁白截斷事故。

結論或引述用 quote，一頁只放一則。
04 / 05
mixed

混合：導語加數字加來源

旁白長度決定頁面長度，不是反過來。

量測
ffprobe
每段 MP3 的實際秒數
回寫
hf sync
頁面、字幕、metadata 一次同步

來源：data/timeline.json（由 hf sync 產生）

一頁最多三個 block；再多就該拆頁。
