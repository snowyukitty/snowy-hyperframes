合理推估方法

以可持續使用為目標

保守

先抓穩定日常量，不追求單日最高壓力測試。

分批

草稿、小批次、人工節奏，降低連續觸發限流的機率。

避開

自動化刷圖、多人共用、轉售式大量生成與高重試率。

合理推估要保守處理。Free 適合偶爾測試；Plus 適合每日少量到中量創作；Pro 才適合密集素材工作。但大量連續、程式化、共用帳號或轉售式使用，最容易觸發限制。

最終結論

不要把隱性額度當穩定 API

Free

每天 1-3 張作測試，遇到限制就停止。

Plus

每天 10-30 張適合穩定專案素材迭代。

Pro

每天 50-150 張適合密集工作流，但仍要分批。

建議工作流：低成本草稿 → 精選方向 → 少量高品質定稿 → 保存 prompt 與版本。

最後結論：官方沒有固定每日張數，計畫差異是能力與額度層級，不是公開配額表。做正式專案時，請把圖片生成當成有限資源來排程，先低品質草稿，再少量高品質定稿，才是比較穩定的用法。
